# Heatwave Analysis in India

## Overview

This project implements a data warehouse and ETL pipeline for
analyzing heatwave and weather conditions across selected
locations in India.

## Time Period

2023–2024

## Locations

- Delhi
- Mumbai
- Nagpur
- Kolkata
- Bengaluru
- Guwahati
- Jaipur

## Data Sources

- NASA POWER
- Open-Meteo
- OpenStreetMap

## Technology Stack

- Python
- Pandas
- Jupyter Notebook
- uv
- PostgreSQL
- pgAdmin
- Power BI

## Project Pipeline

Source Data → ETL → PostgreSQL Data Warehouse → OLAP → Power BI
